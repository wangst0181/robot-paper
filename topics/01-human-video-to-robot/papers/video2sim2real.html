Paper 02 · Full-stack skill acquisition

Video2Sim2Real：把一段人类视频变成可优化、可迁移的完整机器人技能栈。

Full-Stack Autonomous Dexterous Skill Acquisition from a Single Human Video。方法先用现成基础模型重建可运行的数字孪生与粗动作先验，再用物体中心关键帧把“动作看起来像”改造成“动作真的影响对象”，最后用 IL 与残差 RL 分工吸收几何和接触误差。

一句话路线

先把视频转成数字孪生和粗机器人轨迹，再只在接触、交互、脱离等“决定物体命运”的关键帧优化机器人构型；IL 校准对象几何，指级残差 RL 修补接触动力学，必要时再由规划器扩展到新摆放。

01 · PIPELINE

这是一个六段式全栈管线，关键桥梁是“物体中心关键帧”。

系统并不把重定向轨迹当成真值：它先识别最有物理意义的时刻，再利用数字孪生中的对象几何、位姿与任务类型纠正机器人构型。

STEP 01

场景理解

Gemini 识别对象与任务；SAM3 / SAM3D 分割并重建对象级网格与 URDF。

digital twin S
STEP 02

动作先验

HaMeR 估计人手 3D 关键点，Mink 重定向到机器人；CoTracker + 深度得到对象 3D flow。

raw robot / object traj.
STEP 03

关键帧检测

从物体运动识别接触 Tc、交互 Ti 与脱离 Td，而非按时间均匀采样。

object-centric anchors
STEP 04

轨迹校正

按抓取/推/拉任务优化关键帧机器人构型，再用 IK 与插值修正整条轨迹。

refined base trajectory
STEP 05

解耦迁移

IL 从点云回归关键帧手姿；残差 RL 只修正手指，适应摩擦、质量与控制误差。

robust policy stack
STEP 06

部署与扩展

初始点云一次校准，执行中结合对象反馈加指级残差；可选规划器处理远距离新摆放。

real robot skill
INPUT
视频 + 一张清晰参考 RGB-D 图另含相机内参，以及相机、桌面和机器人基座间外参。
不需要机器人示范、动作标签或人工奖励。
TWIN OUTPUT
对象级可运行场景 S每个对象含语义、掩码、规范网格、桌面坐标位姿、URDF；另含操作对象、目标对象与任务类型。
不只是视觉重建，而是 simulator-ready 资产。
MOTION PRIOR
粗机器人轨迹 + 对象 3D flow前者提供人体动作的平滑时序结构；后者提供真正的任务结果和接触方向线索。
两种先验在关键帧处汇合。
POLICY OUTPUT
几何校准的基准轨迹 + 指级残差全局运动由关键帧姿态、IK 和插值产生；RL 不重写整臂，只做局部手指修正。
保留平滑、安全，同时适应接触。
02 · REFINEMENT

关键帧不是视频摘要，而是动作因果链上的三个锚点。

检测依据来自被操作物体与目标对象的运动变化；校正目标则随抓取、推动、拉取的任务类型改变。

CONTACT · Tc

第一次持续改变物体的时刻

以操作物体 2D flow 点质心相对初始帧的持续位移检测。抓取任务通过 Lightning Grasp 产生候选并在仿真中过滤；推/拉任务根据 3D 对象流方向选择表面接触点并对齐指尖法向。

INTERACTION · Ti

操作对象与目标对象关系改变

从两类对象相对运动的持续变化检测。通过 3D flow 对应点的刚性 SE(3) 配准估计物体姿态，再与接触时已校正的手-物体变换组合，得到交互帧手姿。

DETACHMENT · Td

完成作用并释放对象

接触之后，当操作物体回到靠近桌面的高度阈值下时触发。利用注册后的 3D flow 所估计的目标位姿，优化释放时的手姿。

结构化解读

在“全信”与“全丢”之间选择稀疏信任

完整重定向轨迹保留人类动作的时间连贯性，但会继承估计误差；完全依赖 RL 又带来高维探索。关键帧法只重算最影响物体状态的构型，其余部分用原轨迹和插值维持顺滑。

轨迹构造

锚点化校正

raw retargeted trajectory
+ optimized {q(Tc), q(Ti), q(Td)}
→ IK anchors → interpolation → refined trajectory

关键帧手姿先变换到机器人基座坐标，再通过 IK 变成关节空间锚点，最终与原始重定向轨迹分段插值。

结构化解读

对象信息决定“动作是否有用”

人体手势只说明动作的大致形状。抓取候选能否稳定、推力方向是否正确、释放位姿是否完成任务，都必须在重建对象的几何和物理语境中判断。

03 · SIM-TO-REAL

把迁移误差按尺度拆开：IL 管全局几何，RL 管局部接触。

作者避免让单一策略同时处理点云缺失、对象位置偏差、网格误差、摩擦和控制增益变化，从而保护已校正轨迹的平滑与安全属性。

IMITATION LEARNING · GEOMETRY

点云 → 关键帧机器人手姿

  • Mask-aware PointNet 风格残差网络，输入对象点云。
  • 预测相对对象质心的平移残差与 6D 旋转表示。
  • 训练时随机对象位姿、坐标抖动和点丢弃，模拟噪声与不完整几何。
  • 部署时只在机器人进入工作区前查询一次，避免手臂遮挡观测。
RESIDUAL RL · PHYSICS

基准手指轨迹 + 局部关节残差

  • MLP-PPO 观测当前/下一参考关节、3D flow 质心和物体运动增量。
  • 动作只输出手指关节残差，不改写整臂基准运动。
  • 任务无关的 3D flow 跟踪奖励 + 残差动作惩罚。
  • 随机化观测、动作、控制增益、对象尺寸、质量和摩擦。
REAL 01
采集初始 RGB-D，并跟踪对象点云SAM3 与 CoTracker 给出实机对象观测。
建立当前对象几何与位姿证据。
REAL 02
IL 预测当前场景下的关键帧手姿把仿真中优化出的构型重新校准到真实点云。
处理几何/感知偏差。
REAL 03
IK + 插值重新生成基准轨迹以实机关键帧姿态更新整段平滑运动。
保持全局运动连贯和避碰结构。
REAL 04
残差 RL 在每一步修正手指利用实时对象反馈补偿摩擦、质量与接触动力学差异。
处理局部物理偏差。
04 · EVIDENCE

关键帧校正提高仿真可执行性，解耦策略提高真实迁移率。

实验覆盖 7 项日常操作任务，分别比较轨迹校正策略与 sim-to-real 策略。

91.4%

仿真平均任务成功率

关键帧校正方法在 7 个任务的跨任务汇总中，同时达到最高成功率、最高安全率与最低轨迹 jerk。

05 · BOUNDARY

全栈并不等于无假设：稀疏关键帧、启发式检测和刚体重建仍是边界。

论文把这些限制明确列为后续方向，也给出了 RGB-only、自动标定和触觉残差适配的扩展路线。

只在稀疏关键帧校正

对需要连续在手重定向的任务，三个关键时刻可能不足，未来需要连续轨迹优化。

关键帧检测仍是启发式

依赖对象运动阈值和关系变化；复杂长时任务需要更通用的预训练运动理解模型。

只支持非关节对象

当前对象级重建与 URDF 生成针对刚体；抽屉、剪刀等关节对象需要更一般的重建管线。

仍需深度与预标定

系统使用 RGB-D 和预放置 AprilTag 获得坐标变换；RGB-only 深度估计与自动标定是论文提出的后续方向。
